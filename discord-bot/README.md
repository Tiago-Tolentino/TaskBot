# TasksBot

A documentação principal está no [README da raiz do repositório](../README.md).

Ela reúne instalação, configuração do Discord e do ClickUp, comandos `/help`, `/test` e `/ticket`, filtros, avisos automáticos, menções e testes.

Os comandos npm devem ser executados nesta pasta:

```sh
npm ci
npm start
```

Antes de iniciar pela primeira vez, crie `.env` a partir de `.env.example` e preencha sua configuração conforme o README principal. Preserve um `.env` já existente.
